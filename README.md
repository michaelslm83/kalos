# KALOS: קליסתניקס, המדריך המקצועי

אתר הדרכה ואימון בעברית (RTL) על קליסתניקס. הוא כולל:
- 44 תרגילים עם הדגמות מונפשות (ביצוע נכון מול טעות נפוצה) וסרטון Kalo לכל תרגיל.
- מסלולי התקדמות ועץ סקילים.
- 7 תוכניות מוכחות, כל אחת ב־3 שלבים עם רצועת Kalo, ומחולל תוכנית אישית.
- מבחן כושר כניסה.
- אימונים מודרכים ואתגרים.
- יומן אימונים עם גרפים והישגים.
- כלים: טיימר אינטרוולים, מחשבון כוח יחסי ומחשבון חלבון וקלוריות.
- מצא פארק: מתקני כושר ומגרשים ציבוריים בקרבתכם, עם ניווט.
- עברית ואנגלית (כפתור EN/עב בסרגל העליון, או `?lang=en`), ותפריט נגישות עם הצהרת נגישות.

**הנתונים נשמרים רק בדפדפן** (localStorage, מפתחות `kalos.*`). אין חשבונות ואין שרת. כדי להעביר נתונים בין מכשירים משתמשים בגיבוי ובשחזור.

## טכנולוגיה
- HTML/CSS/JavaScript סטטי. אין build ואין תלויות.
- ההדגמות הן מנוע SVG עצמאי (`assets/js/figure.js`): שלד דו־ממדי עם קינמטיקה הפוכה ותנוחות מפתח לכל תרגיל.
- סרטוני Kalo (`assets/js/kalo.js`) נוצרים בזמן אמת ממנוע ההדגמות. אין קובצי וידאו ואין רשת, הם וקטוריים ועובדים בכל דפדפן עדכני. נגן עם פרקים, גרירה בציר הזמן, מקלדת (רווח/K, חצים, F), מסך מלא אמיתי ומסך מלא מדומה ב־iPhone, ויחס 4:5 במסכים צרים.
- תמונות: Pexels (רישיון חופשי), מאוחסנות מקומית ב־`assets/img` (WebP, ‏800px ו־1600px). גופנים: Heebo ו־Rubik (SIL OFL), מאוחסנים מקומית ב־`assets/fonts`.
- פארקים: Overpass API ו־Nominatim של OpenStreetMap (נתונים ODbL, עם קרדיט באתר). המפה היא הטמעה של openstreetmap.org.
- הנחיות קוליות: Web Speech API, ורק אם יש בדפדפן קול עברי. בלי קול עברי מושמעים צלילים בלבד.

## הרצה מקומית
אפשר לפתוח את `index.html` ישירות בדפדפן, אבל אז אין PWA, אין קישורי שיתוף, ואיתור מיקום בפארקים לא עובד (צריך https או localhost).
לחוויה המלאה, הריצו שרת סטטי:

```bash
uv run python -m http.server 8080
# ואז: http://localhost:8080
```

## הערות
- כל הקבצים מקומיים: גופנים, תמונות וסרטוני Kalo. רק "מצא פארק" צריך רשת (OpenStreetMap). "הפארקים שלי" זמינים גם בלי חיבור.
- מזהי סרטוני YouTube המקוריים עדיין שמורים ב־`KX.videos` (`data.js`, `exercises-extra.js`) לתיעוד, אבל לא מוצגים באתר.
- **טקסט חדש בעברית צריך תרגום:** מוסיפים את המחרוזת והתרגום שלה למילון, ובונים מחדש את `assets/i18n/en.js`. מחרוזת שחסרה במילון מוצגת בעברית גם באתר האנגלי. ברשימה `KX.i18nMissing` אפשר לראות מה חסר.
- **הצהרת הנגישות:** צריך למלא בה את פרטי רכז/ת הנגישות ואת תאריך הבדיקה (מסומנים "[למילוי]"). בדיקה אוטומטית ובדיקת מקלדת עברו (WCAG 2.1/2.2 AA), אבל עמידה בתקן 5568 דורשת גם בדיקה ידנית של מורשה נגישות.
- מינונים ("3×8–12") מוצגים דרך `KX.bidi`, שמבודד אותם משמאל לימין. בלי זה הדפדפן מציג אותם הפוך בטקסט עברי.
- נבדק באמולציה של Chrome (מנוע Blink): 14 מכשירים מ־280px עד 1920px, בעברית ובאנגלית, ובהגדלת טקסט של 130% ו־150%. לא נבדק על מכשירים פיזיים, ולא ב־Safari (WebKit) או ב־Firefox.
- המחשבונים נותנים הערכות כלליות (Epley, Mifflin–St Jeor, Morton et al. 2018).
- המידע באתר כללי ואינו תחליף לייעוץ רפואי.
- גיבויים: `_backup/2026-11-07/` (לפני הפיצ׳רים), `_backup/2026-11-08/` (לפני האירוח המקומי, סרטוני Kalo ומצא פארק).
