# KALOS: קליסתניקס, המדריך המקצועי

אתר תדמית/הדרכה בעברית (RTL) על קליסתניקס: מה זה התחום, 39 תרגילים עם הדגמות מונפשות (ביצוע נכון מול טעות נפוצה) וסינון לפי אזור בגוף (חזה, גב, כתפיים, ידיים, בטן, רגליים, ישבן, גוף מלא), מסלולי התקדמות, 7 תוכניות מוכחות, מחולל תוכנית אישית, עקרונות בניית תוכנית, ספריית וידאו, גלריה ושאלות נפוצות.

## טכנולוגיה
- HTML/CSS/JavaScript סטטי. אין build ואין תלויות.
- ההדגמות הן מנוע SVG עצמאי (`assets/js/figure.js`): שלד דו-ממדי עם קינמטיקה הפוכה ותנוחות מפתח לכל תרגיל.
- תמונות: Pexels (רישיון חופשי). סרטונים: הטמעות YouTube (`youtube-nocookie`) שמזהיהן אומתו.

## מבנה
| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה העמוד |
| `assets/css/style.css` | מערכת עיצוב, רספונסיביות, הדפסה |
| `assets/js/figure.js` | מנוע ההדגמות |
| `assets/js/data.js` | תוכן: 16 תרגילי היסוד, תוכניות, מסלולים, FAQ |
| `assets/js/exercises-extra.js` | 23 תרגילים נוספים ומיפוי אזורי גוף |
| `assets/js/builder.js` | הלוגיקה של מחולל התוכנית |
| `assets/js/app.js` | ממשק המשתמש |

## הרצה מקומית
אפשר לפתוח את `index.html` ישירות בדפדפן. במצב `file://` הסרטונים ייפתחו בלשונית YouTube חדשה, כי YouTube חוסם הטמעה בלי מקור (origin).
לחוויה המלאה, הריצו שרת סטטי:

```bash
uv run python -m http.server 8080
# ואז: http://localhost:8080
```

## הערות
- התמונות, הגופנים והסרטונים נטענים מרשת חיצונית (Pexels, Google Fonts, YouTube). בסביבה מנותקת צריך לארח אותם מקומית.
- המידע באתר כללי ואינו תחליף לייעוץ רפואי.
