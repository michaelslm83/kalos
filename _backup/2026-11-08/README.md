# KALOS: קליסתניקס, המדריך המקצועי

אתר הדרכה ואימון בעברית (RTL) על קליסתניקס. הוא כולל:
- 44 תרגילים עם הדגמות מונפשות (ביצוע נכון מול טעות נפוצה) וסרטון לרוב התרגילים.
- מסלולי התקדמות ועץ סקילים.
- 7 תוכניות מוכחות ומחולל תוכנית אישית.
- מבחן כושר כניסה.
- אימונים מודרכים ואתגרים.
- יומן אימונים עם גרפים והישגים.
- כלים: טיימר אינטרוולים, מחשבון כוח יחסי ומחשבון חלבון וקלוריות.

## פיצ׳רים
| פיצ׳ר | איפה |
|---|---|
| אימון מודרך: הדגמה, ספירת סטים, מנוחה אוטומטית, הנחיות קוליות, שמירת המסך דלוק, סיכום ועריכה לפני שמירה | `#workouts`, כפתור "התחל אימון מודרך" בכל יום בתוכנית, וכפתור "אימון מודרך" במודאל של כל תרגיל |
| יומן אימונים, גרף התקדמות לכל תרגיל, נפח שבועי, לוח חודשי | `#me` |
| רצף ימים, רצף שבועות, 19 הישגים | `#me`, ובניווט (🔥) |
| אתגרים: 30 יום שכיבות סמיכה, פלאנק, סקוואט, מתח, ו־21 יום בטן | `#workouts` |
| עץ סקילים (6 ענפים), מסונכרן עם מסלולי ההתקדמות | `#skilltree` |
| מבחן כושר כניסה שממלא את המחולל ומשווה למבחן הקודם | כפתור במחולל וב־`#me` |
| מועדפים לתרגילים ולתוכניות | ☆ בכרטיסים, במודאל ובתוכניות |
| שיתוף: קישור לתוכנית (`#plan=...`), כרטיס תמונה של אימון, WhatsApp | כפתור "שתף" |
| הדגמה מונפשת בריחוף: על כרטיסי התרגילים, ותצוגה מקדימה על כפתורי "הדגמה" בסולמות ובתוכניות. במסכי מגע ההדגמה מתנגנת כשהכרטיס בתצוגה | ספריית התרגילים |
| מצב בהיר/כהה (ברירת המחדל לפי המערכת) | כפתור בניווט |
| PWA: התקנה כאפליקציה ועבודה בלי אינטרנט | `manifest.webmanifest`, `sw.js` |
| גיבוי ושחזור של כל הנתונים לקובץ JSON | `#me` ← "הנתונים שלכם" |

**הנתונים נשמרים רק בדפדפן** (localStorage, מפתחות `kalos.*`). אין חשבונות ואין שרת. כדי להעביר נתונים בין מכשירים משתמשים בגיבוי ובשחזור.

## טכנולוגיה
- HTML/CSS/JavaScript סטטי. אין build ואין תלויות.
- ההדגמות הן מנוע SVG עצמאי (`assets/js/figure.js`): שלד דו־ממדי עם קינמטיקה הפוכה ותנוחות מפתח לכל תרגיל.
- תמונות: Pexels (רישיון חופשי). סרטונים: הטמעות YouTube (`youtube-nocookie`) שמזהיהן אומתו מול oEmbed.
- הנחיות קוליות: Web Speech API, ורק אם יש בדפדפן קול עברי. בלי קול עברי מושמעים צלילים בלבד.

## הרצה מקומית
אפשר לפתוח את `index.html` ישירות בדפדפן, אבל אז הסרטונים נפתחים בלשונית YouTube, ואין PWA ואין קישורי שיתוף.
לחוויה המלאה, הריצו שרת סטטי:

```bash
uv run python -m http.server 8080
# ואז: http://localhost:8080
```
